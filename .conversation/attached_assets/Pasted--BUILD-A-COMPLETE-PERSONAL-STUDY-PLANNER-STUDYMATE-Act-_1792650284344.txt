## 4. WORKING STUDY PLAN GENERATOR

Implement a real scheduling algorithm that generates a personalized daily and weekly timetable using the learner's actual inputs.

The algorithm must:
1. Calculate the time remaining before the examination.
2. Identify weak topics and prioritize them.
3. Allocate more time to difficult topics and topics with low practice scores.
4. Consider topic importance when supplied.
5. Distribute revision across available days.
6. Include breaks between sessions.
7. Include practice questions, past papers, and mock exams when appropriate.
8. Schedule regular revision of previously studied topics.
9. Respect available hours, existing commitments, and daily study limits.
10. Prevent overlapping sessions.
11. Never schedule a session after the relevant examination.
12. Preserve completed sessions when the remaining plan is regenerated.
13. Reallocate missed sessions when the learner requests rescheduling.
14. Warn the learner when there is insufficient time to cover every topic.

Do not create random timetables or display fake AI-generated recommendations. The scheduling algorithm must be implemented in actual application code.

Use sensible default priorities, session durations, and break intervals. Document how the scheduling algorithm works.
